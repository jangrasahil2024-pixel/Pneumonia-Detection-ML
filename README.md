# Pneumonia Detection using Deep Learning

## Overview
This project is a Deep Learning application that detects whether a chest X-ray image shows Normal lungs or Pneumonia.

## Technologies Used
- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Features
- Image preprocessing
- Deep Learning model training
- Model evaluation
- Chest X-ray prediction

## Dataset
Chest X-ray dataset for Pneumonia Detection.
